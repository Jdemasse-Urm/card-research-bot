Gemini API key (required for AI)

Free at aistudio.google.com/apikey (sign in with Google → Create API key). Saved only on this computer, in the app's .env file.

Optional connections

PSA (verify slabs, population, grading progress): free token at psacard.com/publicapi.

eBay (deal finder — live listings under sold value): free keys at developer.ebay.com → Production keyset.
